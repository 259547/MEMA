# MEMA
MEMA - Mobile Electronic Medical Assistant - deafult files of project created to deliver enough help as device for older people with walking problems. Basically working on GPS/GSM and diffrent sensors as: accelerometer( LSM6DSV16BX ) inclinometer (IIS2ICLXTR) and pressure sensor (LPS22HB) coutning height.  Confirming a drop by at least two of them, would trigger delayed alarm and will start procudere of sending message to ICE(InCaseofEmergency) . Device used to be rechargebale by BQ24296RGET and small L-Ion(with certifficate).
